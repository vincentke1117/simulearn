# 储能元件初始值与交流电源初相

电路实验室给三种元件各加了一个可选参数（缺省都是 0，旧电路照常算）：

| 元件 | 参数 | 单位 | 含义 | 影响哪些分析 |
|---|---|---|---|---|
| 电容 | 初始电压 v0 | V | 瞬态开始（t = 0）时电容两端电压，**p 端减 n 端** | 只有瞬态 |
| 电感 | 初始电流 i0 | A | 瞬态开始时流过电感的电流，**从 p 流向 n 为正** | 只有瞬态 |
| 交流电压源 / 交流电流源 | 初相 | ° | 输出 `幅值 · sin(2πft + 初相)`；相量分析里就是相量的角度 | 瞬态、正弦稳态（相量）、频率扫描 |

## 初始值：零输入响应与全响应

- **零输入响应**：电路里没有电源，只给电容 v0（或电感 i0），选「瞬态」运行，看储能怎样经电阻释放。例：1 μF 电容 v0 = 10 V 并 1 kΩ，τ = 1 ms，t = τ 时电压降到 10/e ≈ 3.68 V。
- **全响应**：电源和初始值同时存在。例：5 V 经 1 kΩ 给 1 μF 电容充电、电容 v0 = 2 V，电容电压 = 5 − 3e^(−t/τ)。
- **换路**：实验室的开关只有「断开 / 闭合」两种静态状态，没有「t = 0 时动作」。教材里「开关动作前电路已稳定」的题，先按换路前的电路算出 u_C(0₋)、i_L(0₋)，再把它们填进换路后电路的 v0、i0。
- 直流、结点电压、网孔、戴维宁、相量、扫频都是稳态分析，**不看初始值**。电路里没有电源只有初始值时，只能选瞬态，选别的方法运行前会提示。
- 方向看端子：电容、电感的 p 端在元件左侧（转 90° 竖放时在上方）。旋转只改外观，端子跟着元件一起转，p 端始终是 p 端。
- **初始值和电路矛盾时会被拒绝**：电容和电压源（或别的电容）直接构成回路时，它在 t = 0 的电压由电路决定；电感和电流源（或别的电感）串联时同理。这时给它设一个对不上的初始值（例如电容直接并在 5 V 电压源上却设 v0 = 2 V，或两个初压不同的电容直接并联），物理上要靠 t = 0 的跳变才成立，实验室会提示是哪个元件、该怎么改（把初始值改成电路决定的值，或者串 / 并一个电阻把它隔开），不会给出一条看似正常的曲线。

## 初相：多个交流源

- 只有一个交流源时，初相取多少都不影响幅值，只是所有相量一起转过同一个角度。
- 多个**同频率**交流源时，结果只取决于它们之间的相位差。三相电源就是三个幅值相同、初相分别为 0°、−120°、120° 的电压源。
- 实验室的瞬态里交流源是 **sin** 形式。教材多用 cos 写正弦量：`cos(ωt + φ) = sin(ωt + φ + 90°)`。
  - 只做**相量分析**时，所有源都按同一种写法直接填教材的初相即可，相对相位是对的；
  - 做**瞬态**并要和教材的时间函数逐点对照时，cos 形式的源初相要填 φ + 90°。
  - 同一道题里一个源用 sin 写、另一个用 cos 写，要先换成同一种写法再填。
- 幅值是**峰值**：教材的有效值相量 U∠φ 对应幅值 √2·U。结果面板的幅值也是峰值，有效值 = 峰值 / √2。
