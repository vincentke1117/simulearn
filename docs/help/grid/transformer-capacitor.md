# 变压器分接头与并联电容组

配电网实验室里的两种「教材元件」，对应《电力系统分析》第十二章的两类调压手段：**改变变压器变比**和**并联无功补偿**。

## 做什么

- **变压器**：一条连线，把两条电压等级不同的母线连起来。按教材写法给出「中心挡 ± 挡数 × 每挡百分比」，选当前挡位，潮流就按这个变比算。
- **电容组**：挂在母线上的并联电容器，分成若干组。选投入几组，潮流就按投入的容量算。

两者都用「AC 潮流」分析来看效果：改挡位或投切电容 → 运行 → 看低压母线电压落在哪里。

## 参数

### 变压器（选中连线，类型选「变压器」）

| 参数 | 含义 | 例 12-3 |
|---|---|---|
| 高压侧额定电压 (kV) | 分接头中心电压 | 110 |
| 低压侧额定电压 (kV) | 二次侧额定电压 | 6.3 |
| 每挡 (%) | 每挡改变的百分比 | 2.5 |
| 挡数（±） | 中心挡两侧各几挡 | 2 |
| 当前挡位 | 下拉里直接显示该挡的分接头电压 | −1 挡（107.25 kV） |
| R / X (Ω) | 变压器阻抗，**归算到高压侧** | 2.44 / 40 |

- 连线**起点必须是高压侧母线**，终点是低压侧母线。画反了运行前会提示。
- 分接头电压 = 高压侧额定 ×（1 + 挡位 × 每挡%），变比 = 分接头电压 : 低压侧额定。画布上的标注（如「107.25/6.3 kV」）随挡位变化。
- 普通线路不能连两条电压等级不同的母线，那种情况要用变压器。

### 电容组（从元件栏拖到画布，再连到母线）

| 参数 | 含义 |
|---|---|
| 每组容量 (kvar) | 在母线**额定电压**下一组的补偿容量 |
| 组数 | 一共装了几组 |
| 投入组数 | 当前投入几组，0 到组数之间 |

实际补偿的无功随电压平方变化：母线电压是额定的 1.05 倍时，补偿量约为额定容量的 1.10 倍。

## 怎么读结果

- 母线表同时给出**电压 (kV)**、**额定 (kV)** 和 **Vm (pu)**；画布上母线旁也标出 kV 和 pu。标幺值以该母线的额定电压为基准。
- 越出母线电压上下限的行标红。例 12-3 的低压母线限值设成 1.0～1.1 pu，即 6.0～6.6 kV。
- 支路表里变压器那一行：送端是高压侧送出的功率，含变压器损耗。
- 改了挡位或投入组数之后，画布上的结果会清掉，结果面板标明「参数已改动」：那是改之前的数，点「运行」才是新挡位的结果。

## 例 12-3：选降压变压器的分接头

课程里的两个实验分别是最大负荷（28 + j14 MVA，高压侧 110 kV）和最小负荷（10 + j6 MVA，高压侧 113 kV）。

1. 在最大负荷算例里，从 0 挡开始逐挡运行，记下低压母线电压。
2. 在最小负荷算例里同样做一遍。
3. 找出两种运行方式下低压母线都在 6.0～6.6 kV 的挡位。教材用简化公式（忽略电压降落横分量）选出的是 107.25 kV 挡；这里的潮流是精确解，数值与教材相差约 0.05 kV，结论相同。
4. 再试试投切电容组：在最大负荷、0 挡的情况下投入几组电容，看看能不能不调挡位也把电压抬进范围。
